# 🚀 Groq Voice Tool - AI 智慧語音與桌面效率助理

**Groq Voice Tool** 是一款專為 Windows 設計的高效 AI 桌面工具。整合 Groq 超高速 Whisper 語音辨識、LLM 智慧校對、劃詞翻譯與實時對話，為日常文字輸入與閱讀提供極致順暢的體驗。

---

## ✨ 核心特色

* 🎙️ **高準確率語音輸入**：基於 Groq Whisper 語音辨識，搭配 AI 自動校對同音錯字與全形標點。
* 💬 **AssistiveTouch 懸浮小球**：iPhone 風格極簡小球，不佔用螢幕空間，單擊即可喚起全功能快速選單。
* 🌐 **AI 實時對話與搜尋**：內建全功能對話視窗，支援 Tavily 聯網資料檢索與高階推理。
* 🔍 **全系統劃詞與 OCR**：支援選取文字即時翻譯、AI 潤飾摘要、劃詞原地替換與螢幕區域 OCR 辨識。
* 🔒 **安全保護與隱私**：對話歷史僅留存於本機；內建系統設定鎖，防止誤觸變更。

---

## ⌨️ 快捷熱鍵對照表

| 熱鍵組合 | 功能說明 |
| :--- | :--- |
| `Alt + Q` | 喚起 **AI 實時對話面板** |
| `Alt + S` | 啟動 **語音聽寫輸入** (中文精修) |
| `Alt + Shift + S` | 啟動 **語音中譯英** |
| `Alt + C` | **劃詞翻譯** (選取外文顯示繁中) |
| `Alt + Shift + C` | **劃詞原地替換** (AI 改寫覆蓋) |
| `Alt + A` | **AI 潤飾與摘要** |
| `Alt + X` | **螢幕截圖 OCR 辨識** |
| `Alt + Shift + P` | 一鍵 **暫停/恢復** 所有熱鍵 |

## 🛠️ 快速開始

### 1. 安裝與執行
* 至本倉庫的 [Releases](../../releases) 頁面下載最新版可執行檔。
* 點擊執行即可在桌面右下角喚起懸浮球與系統匣選單。

### 2. API Key 設定
首次啟動請點擊懸浮選單或系統匣的 **⚙️ 系統設定**：
1. **Groq API Key**（必填）：請至 [console.groq.com](https://console.groq.com/) 免費申請。
2. **Tavily API Key**（選填，用於實時搜尋）：請至 [tavily.com](https://tavily.com/) 免費取得。
