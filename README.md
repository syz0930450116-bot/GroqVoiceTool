# 🎙️ GroqVoiceTool  - 全能 AI 桌面助理

基於 **Groq API (Whisper + Llama / Qwen)** 開發的極速 AI 桌面工具。不需要打開網頁，只要透過全域快捷鍵或懸浮小工具，就能在電腦任何地方享有**語音打字、智慧排版、劃詞翻譯、截圖 OCR、萬能指令與連續對話**等強大異能！

---

## 🔥 核心強大功能（解鎖你的工作效率）

*   🎙️ **極速語音打字 (Alt + S)**：對著麥克風說話，自動過濾口語贅字（如「然後、呃」）、自動加標點符號，秒轉流暢的繁體中文並直接貼上。
*   💬 **Spotlight 萬能指令與對話列 (Alt + Q)**：按快捷鍵叫出浮動輸入列，除了能跟 AI 連續對話外，還能直接**語音/文字控制系統音量、開啟記事本/計算機/Steam、查詢即時天氣**！
*   ✨ **自訂 AI 指令與翻譯 (Alt + 1 / Alt + 2)**：不只日文、法文、英文隨你切換！在設定中心自由更改提示詞，一鍵將文字轉為商用信件或精簡摘要。
*   🔍 **劃詞翻譯與原位替換 (Alt + C / Alt + Shift + C)**：反白外文，一鍵彈窗翻譯或直接在原處替換成流暢中文。
*   🖼️ **截圖 OCR 智慧翻譯 (Alt + X)**：框選螢幕上的任何圖片或遊戲畫面，自動辨識文字並翻譯成繁體中文。
*   📋 **自動剪貼簿背景翻譯**：開啟後只要複製文字，背景自動翻譯並覆蓋剪貼簿，看外文資料超輕鬆。
*   🛡️ **遊戲防誤觸暫停模式 (Alt + Shift + P)**：打遊戲或專心工作時一鍵鎖定所有熱鍵，絕不干擾日常操作。

---

## 📥 立即下載與使用

如果你想直接使用打包好的免安裝版：
1. 前往右側的 **[Releases](../../releases)** 頁面。
2. 下載最新的 `.exe` 執行檔，雙擊即可開啟。
3. 第一次使用時，點擊設定按鈕輸入你的 **Groq API Key**（免費申請）即可開始使用！
