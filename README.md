# 🚀 Groq AI 語音與桌面助理 — 初次使用新手指南

歡迎使用 **Groq AI 語音與桌面助理**！這是一款全方位的桌面 AI 效率工具。不論您在 Word 寫作、網頁瀏覽、LINE 聊天或閱讀文獻，只要透過**快捷鍵**或**懸浮工具**，就能隨手完成語音輸入、翻譯、潤飾與 AI 智慧問答。

---

## 📌 一、 第一次使用：只需 2 步驟（約 1 分鐘）

本程式完全免費，但需連結您的 Groq API 金鑰來驅動 AI 雲端模型。

### 步驟 1：免費取得 API Key

1. 開啟 [Groq 官網 Console](https://console.groq.com/)，點擊 **Sign in** 使用 Google 帳號登入。
2. 點擊左側選單 **API Keys** ➔ 點擊右上角 **Create API Key**。
3. 複製產生的金鑰（格式為 `gsk_...`）。

### 步驟 2：貼入金鑰並儲存

1. 開啟軟體後，點擊桌面懸浮工具列上的 **`⚙️` (設定中心)**。
2. 將金鑰貼入 **Groq API Key** 欄位。
3. 點擊 **「儲存並套用」** 即可啟用全部功能！

## 💡 二、 系統化功能分類與快捷鍵教學

### 1. 🎙️ 語音輸入模組（用語音取代打字）

* **`Alt + S` 語音聽寫（純校對不回答）**
* **用法**：按一次開始說話，說完再按一次。文字會自動修訂錯字、加標點並貼在游標處。
* **特色**：說出問句（如：「你覺得怎麼樣？」）只會校對文字，**絕不自動作答**。


* **`Alt + Shift + S` 語音中譯英**
* **用法**：口述中文，自動將語音翻譯為地道英文並貼出。



---

### 2. 💬 AI 智慧對話模組（隨手問 AI / 硬體控制）

* **`Alt + Q` 萬能指令列**
* **用法**：按下後螢幕中央跳出輸入框，支援打字/語音雙模。
* **功能**：
* **AI 答詢**：問問題、寫文章，享受毫秒級流式打字顯示。
* **電腦控制**：輸入「音量調大」、「靜音」、「開記事本」可直接操控 Windows。
* **氣象與搜尋**：輸入「台北天氣」、「搜尋 Groq」自動呈現結果或開啟網頁。




* **`💬聊天按鈕` AI 互動聊天面板**
* **用法**：點擊懸浮工具列的「💬聊天」，可開啟獨立對話視窗進行連續主題討論。



---

### 3. 🔍 閱讀與翻譯模組（文字/截圖即時處理）

* **`Alt + C` 劃詞翻譯**：選取外文後按鍵，彈出視窗顯示繁體中文翻譯。
* **`Alt + Shift + C` 原位替換**：選取外文後按鍵，直接在原本位置將外文替換為繁中。
* **`Alt + X` 截圖 OCR 翻譯**：框選螢幕上任何圖片或帶文字區域，自動提取圖片文字並翻譯。
* **`Alt + T` 語音朗讀**：選取文字後按鍵，使用 Windows 系統語音將內容唸出來。

---

### 4. ✨ 文字潤飾與自訂指令

* **`Alt + A` AI 潤飾與摘要**：選取長文自動整理 3 大重點；選取草稿自動修飾為專業語氣。
* **`Alt + 1` / `Alt + 2` 自訂指令**：可在設定中心自由設定 Prompt（如：翻譯為商用日文、改寫為委婉信件）。

## ⚙️ 三、 系統自動化與貼心設計

| 功能 | 說明 | 設定方式 |
| --- | --- | --- |
| **🚀 開機自動啟動** | 首次開啟時預設啟用，Windows 開機自動背景常駐，無須每次手動雙擊開啟。 | 可在 `⚙️ 設定中心` 勾選/取消 |
| **🛡️ 防誤觸暫停 (`Alt+Shift+P`)** | 全螢幕遊戲或簡報時一鍵暫停所有快捷鍵，避免操作干擾。 | 快捷鍵或點擊懸浮列 `🛡️防` |

| **📜 歷史紀錄抽屜** | 所有語音、翻譯與對話紀錄都會自動儲存，可隨時抽出來查閱與複製。 | 點擊懸浮列 `📜歷` |

## ❓ 四、 常見問題 (FAQ)

1. **重開機後快捷鍵沒反應？**
* 請確認在設定中心有勾選「開機自動啟動」。若無勾選，請至軟體目錄雙擊執行檔一次即可。


2. **錄音後顯示「未設定 API Key」？**
* 請確認已於 `⚙️ 設定中心` 輸入正確的 Groq API Key（開頭為 `gsk_`）並點擊儲存。


3. **想更換 AI 模型或 UI 風格？**
* 可進入 `⚙️ 設定中心` 隨時切換主題風格（如：暗夜駭客、賽博霓虹、極簡純白）或調整 AI 模型。
